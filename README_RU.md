# ОЧЕНЬ КРУТОЙ МОд!!!!

Это очень крутой мод для **Sprocket**!!!
Вы когда нибудь хотели во время миссии выйти из танка и разобраться со всем сами?
Теперь у вас есть возможность это сделать очень круто HEEELLL YEAAAHH!!!!
Берите крутую двустволку и разносите кабины этим танкам!!

![Двустволка](Assets/doom_shoty_shoot.gif)

## Требования

- Sprocket с установленным Mod Manager или на крайняк отдельно BepInEx 6 (IL2CPP) (хотя я не до конца уверен что будет работать)
- Крутые солнечные очки
- Крутая стильная сигара

## Установка

Добавьте `SprocketDoomMod.dll` в модлодер через кнопку "Add mod".

или если у вас нет Mod Manager, то скопируйте `SprocketDoomMod.dll` в:
```
<папка Sprocket>\BepInEx\plugins\
```

## Управление

| Клавиша | Действие |
| :--- | :--- |
| `End` / `F8` | Войти в крутой режим крутости |
| `W` `A` `S` `D`, стрелки | Ходьба, воздушные стрейфы |
| `Пробел` | Прыжок чёрт возьми |
| `Left Shift` | Бег |
| `ЛКМ` | Выстрел |
| `B` | менять картечь на пулю и наоборот |
| `F9` | Режим отрисовки оружия: 3D-меш или 2D-спрайт (отчасти поломанно) |
| `F10` | Оверлей дизеринга (выглядит как дерьмо) |
| `-` / `=` | Громкость музыки и эффектов |
